Privacy Policy

Last updated: September 28, 2026

Purpose

Market Dashboard Archive is a private, single-user utility used to save point-in-time research snapshots to the owner's Google Drive.

Google user data

The application uses the Google Drive drive.file scope. It can create files and folders and access only files or folders created or explicitly opened with the application. It does not request access to unrelated Drive files.

Use, storage, and sharing

Google user data is used solely to create and verify the owner's private research archives. The application does not sell, advertise with, or share Google user data with third parties. OAuth credentials are stored as encrypted GitHub Actions secrets, while archive files remain in the owner's Google Drive.

Retention and deletion

Archive files remain in the owner's Drive until the owner deletes them. The owner can revoke the application's access at any time from their Google Account security settings and can delete all files created by the application.

Contact

Questions can be submitted through the project issue tracker.
