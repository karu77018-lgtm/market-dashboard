# Fresh full-feature diagnostic

Problem: the previous stage4 was a prediction-level combination, not a fresh Jev evaluation with stage3's input. Change: use 8 historical issuer/origin cases chosen without realized-return ranking, restore their exact stage3 features from the frozen local inputs, and actually call Jev twice per issuer (with/without news), three runs each. All 59 original fields are passed by name; missing history stays null. No production files or trading rules are changed.

The numeric reference is the original stage3 distribution for the same issuer/origin/horizon. Equal information is used on both Jev arms. No historical performance feedback is supplied to either arm. No old Jev answer is reused. All matching 30-day issuer descriptions are included without a six-item or 650-character truncation; oversized evidence stops rather than silently shortening. Provider-generated sentiment is not passed. Raw vendor text and responses are encrypted with the existing archive passphrase and preserved in Artifact/private Drive, not published in plaintext. Only public-market candidates are used; private holdings are never read.

Two terminal-return Choice questions per issuer predict five/ten regular sessions, next-session open to end-session close. Bin boundaries derive only from stage3's past-observation support and include zero. Interval conventions are open-left/closed-right. Native source weights within a bin will be preserved when converting probabilities back to returns, so no invented or exponentiated tail value is introduced. These within-bin assumptions still constrain the forecast; the test does not independently forecast a joint price path.

This is a narrow diagnostic after prior results were seen, NOT an untouched holdout or evidence of generalized predictive skill. Source-covered cases are deliberately selected, so the cohort cannot represent all stocks. All parameters and inputs are frozen before calls; no fitting on the eight outcomes occurs. Actual outcomes stay local and are not in the committed input JSON or API state. Source history comes from the same already-authorized recovered library data and public chart archive used for stage123; no new market-data requests are made.

Cap: 16 requests, 48 model runs, US$0.05 with a US$0.003 pre-request reserve. Missing cost metadata or errors stop calls, with no retries or new funding. Primary read/comprehension studies remain separate and their scores are never described as forecast accuracy.
